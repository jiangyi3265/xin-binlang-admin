# 倌榔包装与奖项设置

## 30 元和 50 元包装

在「独立奖池 → 编辑」中选择包装配色、包装图和背景图。棕金装和深蓝装自带默认图片，也可上传替换。

「按批次售价识别」使用兑换码所属批次的售价：30 元对应棕金、50 元对应深蓝。首页会根据单一售价的启用批次识别奖池；同一奖池混用售价时首页使用通用展示，建议两个档位分别建奖池。

输入兑换码后，小程序向服务器识别其实际批次；首页手动选择的包装不会改变兑奖所属奖池。该识别操作不开奖、不消耗兑换码和库存。

如果希望扫包装二维码后立即进入对应配色，制作两款小程序码时分别使用以下页面路径及参数：

| 包装 | 页面 | 参数 |
| --- | --- | --- |
| 30 元棕金装 | `pages/index/index` | `tier=30` |
| 50 元深蓝装 | `pages/index/index` | `tier=50` |

一物一码的入口可使用 `pages/redeem/redeem`，参数为 `code=实际兑换码&tier=30` 或 `tier=50`。最终奖池以服务器记录为准。原来两款使用同一个无档位参数二维码时，无法仅凭该二维码区分包装，可在首页选档，或输入兑换码后自动识别。

## 自己配置奖项

| 内容 | 后台位置 | 说明 |
| --- | --- | --- |
| Logo、首页文案、参与流程 | 品牌与活动设置 | 保存后同步到小程序 |
| 包装、背景、奖池公开展示 | 独立奖池 | 关闭公开展示不影响专用码领取和历史凭证 |
| 红包金额 | 奖品与库存 | 类型选现金红包，参考价值填写实际发放金额 |
| 换购商品与补款 | 奖品与库存 | 类型选加价换购，分别填写商品价值和到店补款 |
| 数量与中奖权重 | 奖品与库存 | 库存决定最多可发放数量；权重决定中奖后分配比例 |
| 总中奖率、售价、有效期 | 产品批次 | 每个批次绑定一个奖池 |

充值微信商户运营账户只补充发红包的资金，不会自动修改红包金额、生成奖项或增加库存。奖项库存与微信账户余额需分别管理。

现金奖品未上传图片或图片加载失败时，小程序显示默认红包图案。修改奖品金额只影响后续新开奖；已开奖的凭证保留原奖品快照。

翻牌结果页的其他 5 张卡片标注「奖品展示」：优先展示当前奖池的其他已启用奖项，再补充其他公开且启用奖池的已配置奖项。排除本次中奖奖品和重复展示内容，先展示不同奖项，不足 5 项时循环展示；没有其他奖项时显示「暂无其他奖项」。换购卡片显示实际补款金额和后台配置的奖品名称。

这些卡片仅用于活动奖品展示，不是额外中奖结果，也不表示顾客错过了某个预先固定的奖项。其他私有或停用奖池、停用奖品不会补充到展示列表。实际开奖仍仅使用兑换码所属奖池，只会发放选中卡片对应的服务器结果。

对于准备延后上线的奖品（例如“加 ¥666 中 iPhone 18 Pro Max 512G”），可以在“奖品与库存 → 编辑”中把“开奖资格”设为“仅展示（不参与开奖）”，并保持奖品启用；“展示权重”控制它在其他卡片中出现的相对机会，填 `0` 表示不展示，数值越小越少出现。每次最多随机展示 5 个其他奖项，候选超过 5 个时低权重奖品会有机会不出现。它不会进入实际抽奖、红包检查或库存扣减，也不会出现在首页固定奖品列表。准备正式开奖时，把“开奖资格”改为“参与开奖”，再确认库存和抽奖权重后保存即可。

「100%中奖」仅在服务器确认批次中奖率为 100%、没有未中奖指定码且库存足够覆盖待用码时展示。仅更改宣传文字不能保证中奖，库存不足会停止兑现相应奖项。
